규칙 (서비스 원칙 — 어기면 그 항목은 화면에 안 나간다)
- 서비스는 호재·악재를 판단하지 않는다. "보통 ○○ 쪽"까지만. '판정' '매수' '매도' '유력' '확실' '~될 거예요' 금지. 종목명 금지(사건 이름 '엔비디아 실적'은 가능).
- 모든 사실·수치에는 출처 URL. 못 찾으면 null로 두고 지어내지 않는다.
- 예상 대비는 '예상보다 높음' / '예상대로' / '예상보다 낮음' 중 하나. 실제값·예상치 출처가 둘 다 있어야 한다. 조사가 갈리면 다수 의견 + spread=true.
- 경로는 아래 기본 관계 목록의 선만 쓴다. 새 연결을 만들지 않는다.
- 시나리오 조건은 확인 가능한 지표·일정만('투자 심리가 회복되면' 같은 것 금지).
- '물가 ▼'는 '물가 오름세 둔화'로 쓴다.
- 관심사 박스 문장 = [사실 한 문장 fact] + [시장이 보는 것 한 문장 watch]. '걱정' 고정 틀 쓰지 않음, '보고 있어요'로 끝냄. 쪽(호재·악재)은 쓰지 않는다.
- 관심사 계기(trigger)는 출처 기사 2개 이상일 때만. 7일 안 발표 때문이면 trigger·fact는 null로 둬도 된다(시스템이 'D-n'과 날짜 문장을 만든다).

칸: oil=유가, job=경기·고용, cpi=물가, rate=금리, fx=달러·환율, gold=금, stock=주식, vix=공포
기본 관계: 유가→물가, 경기·고용→물가, 달러·환율→물가, 경기·고용→금리, 물가→금리, 금리→물가, 금리→금, 금리→주식, 금리→달러·환율, 달러·환율→주식, 공포→주식 (양방향), 경기·고용→주식, 달러·환율→금
